# Videos

Screen recordings for Prax Labs apps, for example the demonstrations Google Play asks for when an app declares a foreground service.

- Keep each file under 100 MB (GitHub's limit); a short screen recording is usually 10 to 30 MB.
- Use clear names, for example `baby-tracker-foreground-services.mp4`.
- Videos must show the real app, with demo data only (no real names or personal information).
